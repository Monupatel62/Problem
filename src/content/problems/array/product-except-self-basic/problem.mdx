Given an integer array `nums`, return an array `answer` where `answer[i]` equals the product of every value in `nums` except `nums[i]`. Do not use division, and produce the result in linear time.

For `[1, 2, 3, 4]`, return `[24, 12, 8, 6]`: the first result is `2 * 3 * 4`, the second is `1 * 3 * 4`, and so on. Zeroes are important. For `[-1, 1, 0, -3, 3]`, only the output at the zero position is non-zero because every other product includes that zero. With two zeroes, every output is zero.

Division by the total product fails when zeroes occur and is explicitly disallowed. Instead, split each result into a left product and a right product. The product of all values before index i multiplied by the product of all values after index i is exactly the desired answer at i.

Create an output array. In a left-to-right pass, write the product of values before each index, starting with 1 for the first position. Then make a right-to-left pass with a running suffix product. Multiply each saved left product by the suffix product before adding the current value into that suffix.

The output array itself stores the prefix products, so aside from it only two running variables are needed. The method works with negative values, one or more zeroes, and large input sizes without sorting or changing the source array. Return the products, not their indices. Each result excludes exactly one original position, even when values repeat.
